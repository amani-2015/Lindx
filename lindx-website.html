About the project

What is LINDX?

LINDX is an independent Linux distribution built on Ubuntu LTS foundations, with the stock kernel replaced by Xamnod — a custom kernel tuned for responsiveness, security, and gaming workloads.

The desktop runs XFCE: kept fast and configurable rather than heavy. LINDX ships with hardened defaults out of the box, so you're not left assembling a secure system after install.

For developers

Build LINDX From Source

Extract an existing ISO, or build LINDX from scratch using the automated build script.

Required tools

squashfs-tools xorriso grub-pc-bin grub-efi-amd64-bin mtools live-boot casper git

Extracting files from an ISO

# mount the ISO and unpack the root filesystem
mkdir -p /tmp/iso-mount
sudo mount -o loop LINDX-v3.iso /tmp/iso-mount

sudo unsquashfs -d squashfs-root /tmp/iso-mount/live/filesystem.squashfs
sudo umount /tmp/iso-mount

Building the ISO

# chroot into the extracted filesystem and customize it
sudo mount --bind /dev squashfs-root/dev
sudo mount --bind /proc squashfs-root/proc
sudo mount --bind /sys squashfs-root/sys
sudo chroot squashfs-root /bin/bash

# inside the chroot: install live-boot, casper, XFCE + LightDM,
# rebuild initramfs, create the lindx user, then exit chroot

# unmount, then repack the filesystem
sudo umount -l squashfs-root/dev squashfs-root/proc squashfs-root/sys

sudo mksquashfs squashfs-root iso-build/live/filesystem.squashfs -comp xz -e boot -noappend

# assemble the final bootable ISO with GRUB
grub-mkrescue -o LINDX-v3.1.iso iso-build --volid LINDX_V3_1 --product-name LINDX --product-version 3.1

The full process — including kernel detection, initramfs rebuild, XFCE + LightDM setup, and GRUB config generation — is automated in build-lindx.sh in the repository.
